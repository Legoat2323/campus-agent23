# 🎓 校园智能 Agent 问答服务（Campus Agent）

面向**新生**的校园问答后端服务。基于 RAG + Function Calling，回答"报到、入学、生活"三类问题。

> 设计出发点：新生不会想"这是教务处还是学工处的事"，他只会想"我现在该干什么"。
> 所以知识库按**报到时间线**组织，而不是按学校部门组织。

---

## 效果

| 指标 | 结果 | 说明 |
|---|---|---|
| 知识库规模 | **40 条问答 / 4 个主题** | 报到前 / 报到当天 / 入学第一周 / 校园生活 |
| 检索命中率 | **8/8 = 100%** | 8 个测试问题，top-2 检索结果含正确答案 |
| 回答命中率 | **8/8 = 100%** | 最终回答含正确答案 |

测试方法见 `test_qa.py`，覆盖 4 个分类各 2 条问题。

## 这个项目的特别之处

RAG 的价值不在"搬运公开信息"——官网能搜到的内容，搜索引擎和通用大模型也能给。

**本项目真正的资产，是那些网上搜不到的经验型信息**，例如：

- 快递点分布：前街（邮政）、后街（中通/申通/多多驿站）、F 区篮球场旁（顺丰/京东/极兔）
- 宿舍门禁一般 11:30，2000 瓦以上电器禁用
- 图书馆刷脸进出，一次可借 3 本
- 校园网在智慧校园认证，免费使用

这些内容只能靠在校生整理，也是这个 Agent 区别于"直接问 ChatGPT"的地方。

## 架构

```
                    ┌──────── 建库（离线，build_db.py）────────┐
 data/*.md  →  按 ## 标题切分  →  嵌入(embedding-2)  →  Chroma
                                                       │
                                              每次重建前清空（幂等）
                    └──────────────────────────────────────┘

                    ┌──────── 问答（在线，main.py）──────────┐
 问题 → 向量检索(top-2) → 拼 prompt → GLM-4-flash
                                    ├─ 需要工具？→ Function Calling（天气）
                                    └─ 直接回答
      → 流式 / 非流式输出 → 写入会话记忆（保留最近 3 轮）
                    └──────────────────────────────────────┘
```

### 关键技术点

| 点 | 做法 |
|---|---|
| **工具调用与流式的时序冲突** | 先做一次非流式请求判断是否调用工具，拿到工具结果后再开启 `stream=True` 生成（流式响应中拿不到完整 `tool_calls`） |
| **切分策略** | 不用固定 `chunk_size` 硬切，按 `## 标题` 切 —— 一条事实一块，不会被切碎，也不会串味 |
| **建库幂等** | 每次先删 `chroma_db/` 再重建，避免重复写入 |
| **数据质量检查** | 建库时统计「待补充」和「请去官网查」这类空答案，直接列出待补清单 |
| **多轮记忆** | 按 `session_id` 隔离，只保留最近 6 条（3 轮），防 token 爆炸 |

## 快速开始

### 1. 安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. 配置 Key

在根目录创建 `.env`：

```
ZHIPU_API_KEY=你的智谱key
```

### 3. 准备数据

`data/` 下放 `.md` 文件，格式：

```markdown
## 问题是这一行

答案写在这里。一条事实一段，可以用多行。
```

### 4. 建库

```powershell
.\.venv\Scripts\python.exe build_db.py
```

### 5. 启动服务

```powershell
.\.venv\Scripts\python.exe main.py
```

打开 <http://127.0.0.1:8000/docs> 调接口。

### 6. 跑测试

```powershell
.\.venv\Scripts\python.exe test_qa.py
```

## 接口

| 接口 | 说明 |
|---|---|
| `POST /chat` | 一次性返回完整答案 |
| `POST /chat_stream` | SSE 流式返回（打字机效果） |

请求体：

```json
{"session_id": "user_1", "query": "什么时候报到？在哪里报？"}
```

## 数据说明

`data/` 下 4 个文件，共 40 条：

| 文件 | 主题 | 条目 |
|---|---|---|
| `01_报到前.md` | 录取通知、学费、档案、户口、党团关系 | 10 |
| `02_报到当天.md` | 校区、接站、报到流程、宿舍、校园卡 | 10 |
| `03_入学第一周.md` | 军训、体检、选课、转专业、奖助学金 | 10 |
| `04_校园生活.md` | 食堂、快递、门禁、图书馆、网络、请假 | 10 |

**数据来源分两类：**

- **官方公开信息**：来自[《2026年新生入学须知（桂林校区）》](https://www.guet.edu.cn/zs/2026/0728/c2214a158488/pagem.htm)
- **在校生经验**：快递点、门禁时间、图书馆规则等，官网无记载

> ⚠️ 数据适用年级为 **2026 级**，日期与电话每年可能调整，跨年使用前需核对。
